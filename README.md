# Bank GoodCredit Credit Risk

End-to-end production credit risk machine learning project for predicting customers at risk of developing a bad credit history (30+ DPD).

## Project Status

🚧 Development in progress

## Planned ML Pipeline

Data Ingestion → Data Validation → Preprocessing → Feature Engineering → Model Training → Model Evaluation → Prediction → Monitoring → Deployment

## Technology Stack

- Python
- Pandas / NumPy
- Scikit-learn
- XGBoost
- FastAPI
- Docker
- GitHub Actions
- AWS S3
- AWS SageMaker

## Project Structure

The project follows a modular production ML architecture separating data processing, feature engineering, model development, inference, monitoring, and cloud deployment.
